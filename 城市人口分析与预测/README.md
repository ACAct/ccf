# 城市人口分析与预测 —— 实现说明

本项目对 `datasets/` 下的多源人口数据进行处理，预测 **40 个城市（city1~city40）2023 年的总人口数**
（常住人口，单位：万人），并输出 `submission.csv`。

## 一、数据说明

| 文件 | 内容 | 年份范围 |
|---|---|---|
| 人口规模.xlsx | 40 城市的常住/户籍人口 | 2001–2021 |
| 人口密度.xlsx | 人口密度 | 至 2022（部分城市缺失） |
| 城镇化率.xlsx | 城镇化率 | 2003–2022 |
| 就业信息.xlsx | 失业率 / 从业人员 / 三次产业就业 | 2001–2022 |
| 工资水平.xlsx | 职工平均工资（宽表） | 2001–2021 |
| 年龄结构.xlsx | 0-14 / 15-64 / 65+（普查年） | 2000/2010/2020 |
| 生活水平.xlsx | 收入/消费（6 张宽表） | 2011–2022 |
| test.xls | 1 个验证示例城市（已含 2023 答案 384） | 2014–2023 |

- 训练/预测对象：40 个城市，人口到 2021 年，其它特征到 2022 年。
- `test.xls` 是已给出 2023 答案的验证示例，不作为预测目标。

## 二、技术路线（优化流水线）

```
数据清洗 → 保证城市-年份连续 → 构造高质量人口特征(170) → 特征精简(170→70)
→ 构造历史预测样本 → 严格 Walk-forward OOF → LightGBM 参数优化
→ Density Ratio 加入 → Trend/Ridge/CatBoost 辅助 → 获得所有模型 OOF
→ 真实人口 MSE 评价 → NNLS 优化 Ensemble 权重 → 多步递推回测
→ 确定最终模型 → 全部历史数据训练 → 2022→2023 递推 → 后处理 → submission.csv
```

核心思想：
1. **预测增长率而非人口**：`Growth_{t+1} = (P_{t+1}-P_t)/P_t`，`P_{t+1} = P_t(1+Growth_{t+1})`。
2. **两步递推**：人口到 2021，故先由 2021 特征预测 2022，再由 2022 特征预测 2023。
3. **城市-年份连续**：补全缺失年份，保证滞后特征按正确年份计算。
4. **特征精简**：LightGBM 特征重要性选前 70 个（剔除缺失率 >60% 的特征）。
5. **多模型融合**：LightGBM（网格调参）+ CatBoost + Ridge + 历史趋势模型 + 密度比例模型，
   用 NNLS 在人口 MSE 意义下优化融合权重。

## 三、运行方式

依赖：`pandas numpy scikit-learn scipy lightgbm catboost openpyxl xlrd`

```bash
python solution.py            # 脚本版
# 或 Jupyter 打开 城市人口分析与预测.ipynb 逐格运行
```

输出：`submission.csv`（`city_id, year, pred`，40 行）。

## 四、结果

时间序列 Walk-forward 交叉验证（1 步预测，人口层面 MSE）：

| 模型 | OOF 人口 MSE |
|---|---:|
| CatBoost | 399.93 |
| LightGBM（调参后） | 400.93 |
| 历史趋势模型 | 447.34 |
| Ridge | 457.52 |
| 密度比例模型 | 229639.30 |
| **NNLS 加权融合** | **395.91** |

融合权重：LightGBM 0.444、CatBoost 0.490、Ridge 0.001、趋势 0.065、密度 0。

多步递推回测（留出 2020、2021 验证，用 2019 及以前数据训练）：

- 1 步（预测 2020）人口 MSE = 1990.97
- 2 步（预测 2021）人口 MSE = 3556.61

最终 40 个城市 2023 年人口预测（示例）：

```
city_id, year, pred
city1,   2023, 356.54
city2,   2023, 812.68
city3,   2023, 1881.82
city4,   2023, 123.53
...
city40,  2023, 343.25
```

预测年均增长率约 0.7%～5.9%（中位数约 2.5%），与各城市近期趋势一致。

## 五、说明

- **数据清洗**：修正 `生活水平.xlsx` 中城市名录入错误（`ctiy22/ctiy31` → `city22/city31`）。
- **密度比例模型**在本数据上效果很差（密度与人口变动不同步），仅作基线报告，不参与融合。
- **两步递推误差**会随时间累加（回测 2 步 MSE 高于 1 步），这是多步预测的固有特点。
- 若 `submission.csv` 写入报 `PermissionError`，请关闭占用该文件的 Excel/程序后重试。
