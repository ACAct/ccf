# 成员四：科研智能体前端

本目录为**成员四（前端负责人）完成部分**，用于展示科研智能体从任务创建、实验执行到结果分析和论文生成的工作状态。

前端采用原生 HTML、CSS 和 JavaScript，无需安装依赖或执行构建。当前提供演示数据，并已预留真实任务 API 与实验文件读取接口。

## 一、已完成内容

| 模块 | 已实现功能 |
| --- | --- |
| 任务中心 | 任务列表、关键词搜索、状态筛选、创建科研任务、进入实验监控 |
| 实验监控 | 五阶段科研流程、实验配置、训练进度、实时指标、损失与准确率曲线、资源占用、运行日志 |
| 实验控制 | 启动、暂停、继续、停止按钮，以及手动刷新和 5 秒自动刷新 |
| 结果分析 | Val/Test 的 Accuracy、Precision、Recall、F1，支持 Macro/Weighted 和 Loss/Accuracy 曲线 |
| 论文展示 | 英文题目、摘要、关键词、章节结构，以及真实 PDF 的预览与下载 |
| 数据源管理 | 演示/真实数据源切换、任务 API 地址配置、实验文件根路径配置、连接测试 |
| 界面适配 | 桌面端与移动端布局、加载状态、空状态、错误提示和操作反馈 |

## 二、技术栈

- HTML5：页面结构与弹窗。
- CSS3：页面布局、响应式样式和流程步骤条。
- JavaScript：页面路由、状态管理、日志解析和交互逻辑。
- ECharts：训练过程曲线。
- Fetch API：任务接口与实验文件读取。

## 四、启动方式

### 1. 启动静态服务

在项目目录打开 PowerShell，执行：

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

### 2. 打开前端

浏览器访问：

```text
http://127.0.0.1:8080
```

建议使用 Chrome 或 Edge。请通过 HTTP 服务访问，不要直接双击 `index.html`，否则真实模式下的文件读取可能受到浏览器安全策略限制。

## 五、页面入口

| 页面 | 地址 |
| --- | --- |
| 任务中心 | `http://127.0.0.1:8080/#/tasks` |
| 实验监控 | `http://127.0.0.1:8080/#/monitor` |
| 结果分析 | `http://127.0.0.1:8080/#/results` |
| 论文展示 | `http://127.0.0.1:8080/#/paper` |

未选择任务时，监控、结果和论文页面会提示先选择任务。

## 六、数据源使用

点击左下角 **“数据源与接口说明”**。

### 演示数据

默认模式，可直接体验：

- 新建任务。
- 切换实验。
- 启动、暂停、继续和停止。
- 查看训练曲线、指标和论文页面。

演示数据只用于前端展示，不代表真实实验结果。

### 真实数据源

选择“真实数据源”后填写：

- **任务 API 地址**：例如 `http://127.0.0.1:8000`，末尾不需要添加 `/api`。
- **实验文件根路径**：能够访问 `logs/` 和 `results/` 的 HTTP 地址。

配置保存在浏览器本地。点击“测试连接”后，前端会请求 `GET /api/tasks` 检查服务是否可用。

## 七、已对接的接口

### 成员一：任务 API

```text
GET  /api/tasks
POST /api/tasks
GET  /api/tasks/{task_id}
POST /api/tasks/{task_id}/actions
GET  /api/tasks/{task_id}/paper
```

任务控制请求体：

```json
{
  "action": "start"
}
```

`action` 支持 `start`、`pause`、`resume`、`stop`。

### 成员二：实验文件

```text
config.json
metrics.json
logs/<experiment_id>.log
results/runs/<experiment_id>/config.json
results/runs/<experiment_id>/metrics.json
results/runs/<experiment_id>/loss_curve.png
results/runs/<experiment_id>/accuracy_curve.png
```

前端已实现：

- 读取 `model`、`strategy`、`data_ratio`、`epochs` 等配置。
- 解析 JSON Lines 或键值格式的训练日志。
- 使用最新有效日志更新 Epoch、Loss、Accuracy、F1、学习率和耗时。
- 读取 Val/Test 的 Macro、Weighted 指标。
- 加载 Loss 和 Accuracy 曲线图片。

完整字段、请求示例和响应示例见 [前端接口说明.md](./前端接口说明.md)。

## 八、与其他成员的分工边界

本部分只负责**前端展示、交互和接口调用**，不包含：
