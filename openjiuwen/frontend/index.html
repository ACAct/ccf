成员一 · 任务接口约定

GET/api/tasks任务列表
POST/api/tasks创建任务

POST/api/tasks/{id}/actionsstart / pause / resume / stop

成员二 · 实验文件约定

results/runs/<experiment_id>/config.json不存在时回退到根目录 config.json
logs/<experiment_id>.log逐行日志，最后一行作为最新训练状态
results/runs/<experiment_id>/metrics.json验证集与测试集指标
results/runs/<experiment_id>/loss_curve.png损失曲线
results/runs/<experiment_id>/accuracy_curve.png准确率曲线

日志支持 JSON Lines，或包含 epoch、train_loss、train_acc、val_loss、val_acc、val_f1、lr 的键值文本。真实模式下文件服务需允许浏览器跨域读取。
